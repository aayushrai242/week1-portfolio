# Skill Nexis Week 4 — Student Management Dashboard

A responsive student dashboard built with HTML, CSS, and vanilla JavaScript.

## Assignment requirements covered
- Add, edit, and delete student records (CRUD).
- Persist records in browser `localStorage`.
- Styled student table with name, email, roll number, department, year, and status.
- Live search across student name, email, roll number, department, and year.
- Filter by department and active/inactive status.
- Form validation and duplicate roll/email checks.
- Responsive layout, empty state, and feedback messages.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Add, edit, search, filter, or delete student records.
4. Records are saved in that browser's `localStorage`. Use the same browser on the same device to see saved data. Clearing browser site data may remove records.
5. Four sample records are included on first load; you can edit or delete them.
