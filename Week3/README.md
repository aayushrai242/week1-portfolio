# Skill Nexis Week 3 — Weather App

A responsive city weather app built with HTML, CSS, and JavaScript. It uses the Fetch API to request current weather from OpenWeatherMap and reads the JSON response.

## Assignment requirements covered
- City name input.
- Current temperature (°C), humidity, weather condition, and wind speed.
- Fetch API request to OpenWeatherMap's current weather endpoint.
- JSON response handling and useful loading/error states.
- Clean responsive card UI.

## Important: API key required
OpenWeatherMap requires an API key for live weather data. This project does not include a key.

1. Sign up at https://home.openweathermap.org/users/sign_up
2. Create or find your API key in your OpenWeatherMap account.
3. Open `index.html` in your browser.
4. Expand **API key settings**, paste your key, and enter a city (for example, London or Greater Noida).
5. Click **Check weather**. A newly created key may take some time to activate.

The page keeps the key only in the current page's input field; it does not save it. Do not commit your personal API key into GitHub. For a public production application, use a backend to protect API credentials.

## Run locally
Extract the ZIP and open `index.html` in a modern browser. Internet access is needed for the weather request.
