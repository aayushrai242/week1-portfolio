# Skill Nexis Week 2 — Digital Clock / Countdown Timer

A responsive digital clock and countdown timer built with HTML, CSS, and vanilla JavaScript.

## Assignment requirements covered
- Live local time displayed in `HH:MM:SS` format.
- Clock updates every second with `setInterval()`.
- Uses JavaScript `Date` to read local time and format the date.
- Optional countdown timer to a user-selected future date/time.
- Event name can be customized; invalid/past dates are checked.
- Responsive layout for desktop and mobile.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.
3. The clock starts automatically. Choose a future target date/time, optionally change the event name, and click **Start countdown**.

## Upload to your existing GitHub repository
Recommended: keep Week 1 and Week 2 in the same repository, in separate folders.
1. Open your `week1-portfolio` repository on GitHub.
2. Click **Add file → Create new file**.
3. In the filename box, type `Week2/index.html`. Paste the contents of this project's `index.html`, then commit.
4. Repeat for `Week2/style.css`, `Week2/script.js`, and `Week2/README.md`, pasting each matching file's contents.
   - Alternatively, use **Add file → Upload files** and upload the four files while inside the `Week2` folder if GitHub offers that folder path in the filename/drag workflow.
5. The repository link remains `https://github.com/YOUR-USERNAME/week1-portfolio`. If Skill Nexis asks for a live website link, you can publish with GitHub Pages and use the `/Week2/` page URL.

Copy your actual GitHub repository URL and paste it in the Skill Nexis Week 2 Project / Assignment Submission box. If the platform specifically requires a live URL, configure GitHub Pages in repository **Settings → Pages** first.
